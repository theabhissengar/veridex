# Evaluation

Metrics are computed per case, then macro-averaged. The published number uses the evaluation tier only. Development validation is for calibration.

Detector confidence, observation strength, and case assessment are separate scores. Coverage suggestion accuracy is separate from final-coverage accuracy.

False accusation rate is the share of cases whose generated report sections 7–11 fail the blame-language check or whose assessment names a party as the cause. The target is zero.
